# 租房系统-房东端

面向房东的房屋采集与三维预览工具。当前方案聚焦简单登录、用户中心证件核验 Mock（身份证两面与房产证）、实时拍摄、素材暂存、Agent 指导，以及重建后的内部预览与质检。

**当前已实现可运行的本地最小 MVP，使用浅色界面。支持真实登录、实时相机采集和持久草稿；证件核验为流程 Mock，外部 Agent 与重建服务可选配置。**

账号准备：登录 → 用户中心 → 身份证人像面、国徽面与房产证 Mock 核验 → 标注通过。未通过时禁止新建和继续采集，服务端同时拦截主线写入。

本机开发时，用户中心会额外显示“开发模式：跳过证件核验”。它不选择、上传或保存任何证件图片，状态会明确显示为“开发已跳过”；仅在未配置 `PUBLIC_ORIGIN`、且 `NODE_ENV` 不是 `production` 时默认可用。生产部署应设置 `NODE_ENV=production`（或 `DEV_IDENTITY_BYPASS=0`）以关闭此入口。

采集主线：现场采集 → 拍后复查 → 空间成果。证件核验不占用主线步骤；通过后返回“我的采集”创建房屋/房间记录，随时暂存或补拍。

房屋采集没有相册或文件导入入口；另提供独立的本地 PLY 预览入口，文件仅在当前浏览器会话中读取，不会上传至 Aholo、写入采集素材或持久保存。已完成的照片/视频素材保存在本机 Node 服务的 SQLite 与素材目录，刷新、退出登录或重启服务后均可恢复。未配置视觉模型时，只做真实的本地亮度/数量检查和基础建议；不冒充视觉 Agent。无完整管理后台、租客端或公开发布功能。

## 启动

需要 Node.js 24+。在本项目目录执行：

```powershell
npm ci
npm run build
npm start
```

打开 [本机体验入口](http://localhost:4317)。首次启动生成 `landlord` 账号和随机密码，查看 [.data/local-login.txt](.data/local-login.txt)。该文件、数据库、素材和 `.env` 均不纳入 Git。

默认监听 `127.0.0.1`，供当前电脑上的 Edge/Chrome 使用。手机拍摄需要另行配置可信 HTTPS 访问；本轮没有部署，也未承诺局域网 HTTP 可以开启手机相机。

| --- | --- |

| 核验准入与通过标记 | 状态持久化；未通过/重新核验阻止主线，旧版仅身份证通过需补做三项核验 |
| 实时拍照、录像、暂停/结束、保存重试 | 已实现；测试通过真实浏览器相机 API 与测试摄像头完成 |
| 草稿、原始素材、备注与复查记录持久化 | 已实现，服务重启恢复测试通过 |
| 弹幕指导、拍后问题与补拍入口 | 本地基础检查已实现；视觉模型适配器已做本地 HTTP 桩测试 |
| AI 房源概览 | 方舟文本模型适配器已实现；仅由用户点击后发送脱敏采集摘要，不发送证件、内部备注或原始媒体 |
| 重建提交、版本防重、状态与下载 | Aholo 适配器已实现；新付费任务仅做桩测试，未实际调用 |
| 三维预览 | 环绕/平移/漫游、WASD 与 QE 移动键、初始点、缩放、全屏；仅在当前房源的 Aholo 任务成功且返回模型资产后加载，无默认样例 |

```powershell
npm run check
npm test
npm run test:e2e
```

新克隆的源码仓库不含任何内置模型；浏览器测试不依赖样例资产。三维预览仅使用完成重建后由当前房源任务返回的 SPZ 或 PLY。

2026-09-12：生产构建、接口/适配器/导航用例和 Edge 浏览器测试已完成。E2E 使用已安装的 Microsoft Edge、测试摄像头和触屏模拟，服务及数据与体验入口分离。真实手机、真实房间、真实视觉 Agent 与新重建效果仍需验收。
