# 房东采集台 · 最小 MVP 使用说明

日期：2026-09-12。依据产品方案 v0.2，当前交付一个可运行的本地应用。

## 五分钟体验

1. 在项目目录执行 `npm ci`、`npm run build`、`npm start`，打开 <http://localhost:4317>。
2. 用首次启动生成的账号登录；随机密码位于 `.data/local-login.txt`，默认账号为 `landlord`。后台校验密码哈希和会话，登录有效期默认 8 小时。
3. 登录后进入“我的采集”。在“用户中心”分别选择身份证人像面、国徽面和房产证（可直接使用示例），提交模拟核验。成功后标注“已通过 · Mock”，返回“我的采集”创建房屋/房间记录。核验独立于主线，不接真实认证，也不保存证件图片。
4. 点击“开启实时相机”，允许浏览器相机权限。拍照或录制视频，右侧可开关实时弹幕。照片用途可选择“重建照片”或“检查近照”。
5. 每次拍摄完成后自动保存。看到“已保存”再退出；失败时保留页面并点击“重试保存”。“暂存并退出”会先结束和保存录像，草稿可从首页恢复。
6. 结束采集，点击“检查已拍素材”。查看问题与依据，记录说明或按建议补拍。新增/移除素材后旧检查失效，需重新检查。
7. 人工回看并勾选确认，进入成果页。未配置 Aholo 时可以下载采集报告、继续补拍，或查看已有三维样例。

主线仅有“现场采集 → 拍后复查 → 空间成果”三个步骤。证件通过状态仅代表账号 Mock 核验已完成，不能证明身份或房屋权属。房屋页面没有导入入口，但浏览器相机本身不构成防翻拍、防虚拟摄像头或时空真实性证明。

## 用户中心与采集准入

- 三项资料均必需：身份证人像面、身份证国徽面、房产证。本版按账号核验，不建立每套房屋与证件的权属绑定。
- 未核验、模拟未通过或开始重新核验时，不能新建/继续采集、上传素材、修改复查、人工确认或提交重建。服务端还校验实时指导、素材删除和任务刷新；绕过页面直接请求同样返回 `403 VERIFICATION_REQUIRED`。
- 登录、退出、用户中心、已有草稿/素材/报告的只读访问和独立样例仍可使用。核验中不删除草稿，不撤回已被外部平台受理的任务。
- 通过状态保存在 SQLite；刷新、重新登录和重启服务后保留。旧版只有身份证的 `identity_mock` 标记不再作为准入依据，须补做三项 Mock 核验。
- 点击“重新核验”立即暂停准入；替换/移除测试图片或切换场景会清除原结果。服务器按核验版本拒绝旧页面的过期提交。
- 模拟反光、缺边角、房产证信息页不完整或服务失败时均不通过。请求失败也不会在页面标为通过；可更正后重试。
- 若采集中核验失效，进入用户中心完成核验。未保存素材保留在当前页面内存中，通过后点击“继续保存拍摄素材”；期间不要刷新或关闭页面。

## 保存方式与限制

| 内容 | 保存位置/规则 |
| --- | --- |
| 用户、会话、账号核验状态、草稿、指导、任务状态 | `.data/rental.sqlite`，SQLite WAL 模式 |
| 已完成的照片/录像 | `.data/media/` 原始字节；经当前账号校验后访问 |
| 导入的重建案例 | `sample_imports` 表与 `.data/imports/<案例编号>/model.spz` 或 `model.ply`；归当前账号所有，保存在当前服务 |
| 案例名称、备注与向上方向的修改 | `sample_settings` 表；按账号保存，修改内置样例的信息也只影响当前账号 |
| 身份证与房产证 Mock 图片 | 当前页面内存；通过核验、离开用户中心或退出后清除，不进服务端、草稿、Agent |
| 尚未录完的视频、保存失败的素材 | 当前页面内存；不会标记已持久保存，重试前不要刷新或关闭 |
| 重试同一拍摄 | 沿用拍摄编号；服务端核对内容，已保存不会新增副本或版本 |
| 现场备注 | 内部保存，默认不进下载报告；问题处理说明会进入报告 |
| 容量 | 每份文件 50 MiB、每账号素材 1 GiB、单次采集 200 份（含录像抽帧）、账号最多 100 次采集 |
| 保留期 | 本机保留，不自动清理；本版没有批量管理或跨设备同步服务 |

每次录像最长 60 秒、无音频；优先选择浏览器支持的 MP4，否则保存为 WebM。WebM 可以回看，本版不自动转码，也不以改扩展名代替转码。普通视频重建使用 MP4；不支持时可用至少 20 张实时重建照片。该数量只是接口门槛。

录像保存起始、中间及结束位置的少量抽帧（最多 3 张；短视频通常 2 张），仅用于复查。独立检查近照和录像抽帧都不作为多图重建照片。重建输入有 MP4 时优先使用 MP4，否则使用全部重建照片。

如需备份，先停止本项目服务，再复制整个 `.data` 目录；不要仅复制正在写入中的 SQLite 主文件。初始账号配置只在数据库中尚无账号时生效，不提供注册、角色、改密或找回密码管理页面。

## 两种指导

- **实时弹幕**：相机开启后约每 10 秒给一条短建议，避开主要取景中心，支持关闭。默认实际计算画面亮度、过亮比例，辅以明确标注的基础拍摄建议；不推断场景覆盖。
- **拍后二次指导**：点击检查后，对已保存素材给出问题、依据和补拍动作。默认根据数量、粗略画质、是否有独立检查近照生成问题，房间覆盖保留人工确认。处理说明不把问题自动判为解决。

配置视觉模型后，实时页面另有“启用 Agent 图像分析”勾选项，开启后才发送当前帧；拍后检查先确认发送最多 8 张抽样照片或录像帧。结果必须包含有效素材编号才能关联依据；失败会显示未完成，不沿用旧结果冒充新检查。

## 可选服务配置

复制 `.env.example` 为 `.env`，填入自己的配置并重启服务；密钥只由后端读取，不发送到浏览器，不写入报告。

视觉指导使用兼容 Chat Completions 的多模态接口：

```dotenv
VISION_CHAT_URL=https://YOUR_PROVIDER_HOST/compatible-mode/v1/chat/completions
VISION_API_KEY=your_key
VISION_MODEL=your_enabled_vision_model
```

例如阿里云百炼需按自己的工作空间、地域和模型开通情况填写完整地址，参见 [百炼视觉理解](https://help.aliyun.com/zh/model-studio/vision)。这不是纯文本模型接口，模型须支持 `image_url` 并能返回所要求的 JSON。

Aholo 配置：

```dotenv
AHOLO_API_KEY=your_key
AHOLO_API_BASE=https://api.aholo3d.cn
```

重建走官方资产上传 SDK 和异步重建 API，使用 `scene=space`、`taskQuality=low`、`useMask=false`。参考 [官方快速开始](https://labs.aholo3d.cn/api-docs/quickstart) 和 [OpenAPI 定义](https://labs.aholo3d.cn/api-docs/openapi.json)。

创建前需完成当前素材版本的复查和人工确认，随后明确确认上传并使用平台额度。相同素材版本最多创建一次；按钮点击不会自动重试付费创建。提交结果不明时显示“状态待核对”，先核对平台，当前 MVP 不提供强制重提或手动关联世界编号的管理入口。已有任务可手动刷新状态，不会在启动时自动创建新任务。

平台完成但没有资产时显示“模型资产待处理”；模型加载失败不标记验收通过。采集确认与模型验收是两个阶段。模型地址来自所配置的服务，是否允许浏览器跨域加载仍由提供方决定；失败时保留平台查看与下载入口。

## 三维预览

采用 Spark + Three.js，进入成果/样例页才按需加载三维模块。两处共用同一套交互查看器，提供浅色工具栏、屏幕移动键和大画面全屏。

| 操作 | 用法 |
| --- | --- |
| 环绕查看 | 左键/单指拖动旋转；右键/双指平移；滚轮/双指缩放 |
| 平移模式 | 左键/单指直接平移画面；右键旋转 |
| 自由漫游 | 拖动转头，WASD 前后左右移动，Q 下降、E 升高；滚轮前进/后退 |
| 屏幕方向键 | 在任一模式长按 WASD、Q/E 按钮连续移动；右侧按钮转向、拉近/拉远 |
| 速度与预设 | 慢速/标准/快速；整体、正面、侧面和俯视视角 |
| 初始点 | 点击画面右上角带定位图标的“初始点”，恢复最初的相机位置与朝向；会议室返回平台保存的室内初始位置，工作台返回整体视角，手机和全屏内均可用 |
| 键盘快捷键 | 点击画面后生效：方向键转向，+/- 缩放，R 复位，F 全屏，H 操作说明 |
| 全屏 | 工具栏全屏按钮进入/退出；浏览器不支持时展开大画面，Esc 可收起 |

旋转已调为较低灵敏度并缩短松手后的惯性，漫游拖动和屏幕转向键也同步减速。移动速度选项调节前后左右及升降速度。

移动键仅在预览区域获得焦点时生效，不接管页面其他输入；松开、失焦、切到后台或离开页面后停止。加载期间控件禁用，离开页面取消加载并释放渲染与事件监听。

正面、侧面和俯视预设是相对模型中心的固定观察方向，不是已采集的房间观察点；重置回到该模型的初始视角。会议室初始位置及看向点读取自平台保存的相机配置，并转换到本地查看器坐标。环绕缩放有距离范围，自由漫游没有碰撞或采集覆盖边界限制，迷失时可按 R 返回。移动速度按模型大小设定，不代表真实米数。本版没有整屋拼接、漫游路线、预设观察点编辑、自动尺寸测量或同视角自动配准。

样例页可在“现代办公会议室”和“硬件工程师工作台”之间切换，首次进入优先展示可用的会议室。切换会取消旧加载、释放旧模型，并恢复新模型的初始位置；缺失文件时显示提示与平台入口，下载按钮只显示本机实际可用的格式。

- 会议室：从 [Aholo 已有项目](https://studio.aholo3d.com/viewer?projectId=3FO4K4VCF7LG) 导入，SPZ、PLY 分别保存在 `outputs/aholo/3FO4K4VCF7LG/meeting-room.spz`、`meeting-room.ply`。模型文件已校验，未新建付费重建任务；来源与哈希见 [导入记录](experiments/2026-09-12-meeting-room/import.md)。
- 工作台：继续使用 `outputs/aholo/3FO4K4XNH9NX/workbench.spz` 及同目录 PLY。它来自之前的 35 张工作台照片试验，存在模糊与漂浮伪影。

两份样例都独立于用户房屋采集和核验主线，仅供预览，未标记验收通过；登录后即可查看，开始自己的采集仍需用户中心核验通过。模型大文件在忽略目录内，不随 GitHub 源码上传。样例使用固定项目目录与登录保护的下载接口，旧版工作台下载地址继续可用。

当前成果页提供独立检查近照的放大回看、原始素材下载及 JSON 报告。尚未实现自动生成模型与实拍同视角对照、模型截图上传 Agent 质检、位置标注与最终验收审批。成果始终保留“待人工验收”，报告不输出虚假的通过结论。

## 导入已有重建案例

登录后进入“重建样例”，点击右上角“导入案例”，默认打开 PLY/SPZ 文件选项，也可切换项目链接：

- **本地文件（默认）**：选择 PLY 或 SPZ，名称会从文件名自动填写，可自行修改；备注可选，按模型实际坐标选择 Z 轴或 Y 轴向上。上传保存后自动打开预览，继续使用现有移动键、视角切换和初始点。
- **项目链接**：粘贴 `https://studio.aholo3d.com/viewer?projectId=...`（也支持 `.cn` 和 `/3dgs-model/<项目编号>` 分享地址）。项目需公开且已完成。案例名称可留空，默认使用平台名称；也可填写备注。优先下载 SPZ，没有 SPZ 时尝试 PLY；能读取平台相机时保留初始位置，否则从整体视角打开。

仅接受已有高斯模型：SPZ v2/v3（gzip 封装）、带完整高斯属性的标准小端二进制 PLY；不接受照片、录像、普通网格、ASCII PLY 或压缩 PLY。单个文件最多 150 MiB（界面简写 MB）、最多 500 万高斯点，SPZ 解压后最多 256 MiB；每个账号最多 30 个导入案例。

保存成功后案例加入列表，刷新、重新登录和重启服务后保留。相同 Aholo 项目或相同文件内容与原始导入向上轴重复导入时打开原案例，不重复保存；已有内置样例也会直接打开。链接导入与文件导入分别去重。重复导入会保留原案例的信息，需要改名或补充备注时使用“编辑信息”。本版不提供案例移除或模型文件覆盖更新。

选中案例后，点击预览区右上方“编辑信息”，可修改名称（1–80 个字）、备注（最多 500 个字）与模型向上方向；保存后重新打开当前预览，取消则不保存。导入案例和内置样例均可编辑，修改只影响当前账号。修改方向不会改变原始模型文件或重复导入的判定依据。若其他页面已修改同一案例，会提示重新打开编辑窗口，避免覆盖较新的信息。

只有当前账号可以列出、预览和下载自己的导入案例，内置样例仍供已登录账号查看。模型文件保存在当前服务的 `.data/imports/`；跟随 `.data` 一并备份，不随 GitHub 源码上传。服务端检查文件内容和大小，普通失败/取消清理临时文件；服务进程被强制终止或机器断电后，未完成的文件不进入案例列表，但可能留在磁盘上。

导入期间可点击“取消导入”。如果连接中断、等待超时或关闭页面，请重新进入案例列表确认是否已保存，再决定是否重试。私有、未完成或无法下载的项目会显示原因，可改用符合格式要求的本地文件。

这是独立案例预览功能，登录后即可使用；它不会导入现场采集素材、绕过证件核验或发起新的付费重建，也不自动标注模型验收通过。链接方式依赖平台公开分享接口；接口变更时仍可使用本地文件。当前导入与信息编辑入口已实现，本轮按暂停测试的安排只做静态检查与构建，尚未进行新增接口和浏览器验收。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 打不开页面 | 确认服务仍运行，端口为 4317，且已执行生产构建 |
| 没有本机密码文件 | 如果自己指定了 `BOOTSTRAP_PASSWORD`，使用指定密码；该文件只用于自动生成密码的首次启动 |
| 相机无法开启 | 用本机 `localhost` 或可信 HTTPS；在浏览器允许相机并关闭其他占用程序 |
| 手机访问 HTTP 地址无法拍摄 | 默认服务只监听本机；手机真机需另行配置 HTTPS，这轮未部署 |
| 录像保存失败 | 保留当前页面，重试保存；未成功保存的字节仍在内存，关闭页面会丢失 |
| 登录过期 | 重新登录原账号，已保存记录保留；通过账号核验后可重试保存内存中的素材 |
| 提示未核验/核验未通过 | 前往用户中心补齐身份证两面与房产证并提交模拟核验；旧版身份证通过标记不足以准入 |
| 二次指导失败 | 检查配置/网络并重试；保存的素材不因此丢失 |
| WebM 无法重建 | 继续实时拍照，或在支持 MP4 录制的浏览器采集；不开放历史文件导入 |
| 样例模型缺失 | 此大文件在忽略的 `outputs/` 内，不随源码依赖安装自动下载；页面会提示缺失 |

默认 Node 服务仅在本机运行。更改 `HOST`、配置 `PUBLIC_ORIGIN` 和 `COOKIE_SECURE` 是后续 HTTPS 部署事项，不等同于当前已部署。测试日志和浏览器截图位于忽略目录 `test-results/`、`playwright-report/`；其中测试相机图案不属于用户素材。
